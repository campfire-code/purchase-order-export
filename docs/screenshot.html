采购单对账

在淘宝网页版「已买到的宝贝」页面一键把订单导出成 CSV，用来和入库、采购记录对账。数据只在你自己的浏览器里处理。

怎么用

  1. 浏览器安装 Tampermonkey 扩展，打开下载的 .user.js 文件并点「安装」
  2. 登录淘宝，进入「我的淘宝 → 已买到的宝贝」，页面顶部出现导出工具栏
  3. 点「添加本页订单」，翻页继续添加；需要物流信息时点「添加订单详情」
  4. 点「导出订单数据」得到 CSV；导出前不要刷新页面，用 Excel 打开建议勾选「Excel 格式适配」
交付形式　油猴脚本（TaoBao_BuyerOrdersExport.user.js），仅支持淘宝，需自己登录淘宝
